# supOS 产品视频视觉规范

版本 0.1 · 根据提供的 supOS Free 网页源码及蓝卓 Logo 素材整理，用于产品介绍、功能演示和工业场景视频。颜色及视频制作参数为首版建议，实际品牌标准和 Logo 选用待确认。

## 视觉方向

以深蓝到亮蓝的渐变、白色文字和浅蓝光感呈现产品主视觉。产品讲解使用白底、浅灰蓝界面和蓝色重点，保持画面清晰、留白充分。产品功能镜头优先突出一个操作或信息点。

## 颜色

| 用途 | 颜色 | 来源 |
| --- | --- | --- |
| 深色背景 | `#030814` | 网页首屏渐变 |
| 深蓝 | `#032554` | 网页首屏渐变 |
| 主视觉蓝 | `#0E59BD`、`#4B94FB` | 网页首屏渐变 |
| 操作和重点 | `#3370FF` | 网页演示界面 |
| 浅色背景 | `#F6F8FC` | 网页演示界面 |
| 正文 | `#18191C` | 网页基础文字 |

渐变参考从深色顶部过渡到亮蓝，再过渡至浅蓝或白色。文字应与背景保持清晰对比。

## 字体和文字

网页基础字体使用 Inter，中文回退到苹方、微软雅黑等系统字体。视频可延续这一无衬线风格，标题简短，字幕与背景保持足够对比。发布前在手机上检查字幕和界面文字是否清晰。

## 画面和动效

- 片头使用 supOS 名称、简短主题和蓝色渐变背景。
- 功能演示采用真实界面或明确标注的演示画面，裁切放大当前操作区域。
- 流程图按讲解顺序逐步出现，用蓝色强调当前步骤。
- 动效以淡入、平移和局部放大为主，给观众留出阅读时间。
- 结尾展示产品名称、蓝卓 Logo 和明确的下一步信息。

## 首条视频建议结构

1. 介绍一个具体业务问题。
2. 用简洁图示展示产品处理流程。
3. 展示一个关键操作及结果。
4. 总结价值并展示品牌信息。

## 待确认

品牌正式色值、Logo 使用版本、目标观众、发布渠道、视频画幅、字幕语言和首条视频主题。确认后更新本规范并通过样片验证。

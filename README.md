# supOS 产品视频视觉规范

版本 0.2 · 根据 supOS Free 网页源码和提供的蓝卓 Logo 整理。视频制作建议仍需样片验证。

## 品牌主色

品牌蓝为 **#1448ED**（RGB 20, 72, 237），从提供的彩色 Logo PNG 中不透明蓝色主体像素提取。品牌重点、标题强调、流程高亮优先使用此蓝色。

网页参考色包括深色背景 #030814、深蓝 #032554、浅色背景 #F6F8FC 和正文 #18191C。网页其他蓝色可作为背景或产品界面参考。

## Logo 版本

- 2025蓝卓logo-02.png：横排 Bluetron 蓝卓组合。
- 2025蓝卓logo-03.png：上下排列的蓝卓与 Bluetron 组合。
- 2025蓝卓logo-04.png：横排 Bluetron 蓝卓与 supOS 组合。
- 2025蓝卓logo-04_副本.png：独立 supOS 标识。
- 2025蓝卓logo-05.png、2025蓝卓logo-06.png、2025蓝卓logo-07.png：包含红色图形的版本，浅色内容需在深色背景查看，使用前按画面确认。

使用原始透明 PNG，保持比例和完整图形，避免拉伸、裁切和自行重绘。选择与背景对比清晰的版本。具体组合和版式以品牌负责人确认为准。

## 视觉与文字

以蓝色、白色和浅灰蓝组织画面，产品功能镜头突出当前操作或信息点。网页基础字体使用 Inter，中文回退到苹方、微软雅黑等系统字体。标题简短，字幕与背景保持足够对比，在手机上检查文字可读性。

## 画面和动效

- 片头使用 supOS 名称、简短主题和蓝色背景。
- 功能演示采用真实界面或明确标注的演示画面，裁切放大当前操作区域。
- 流程图按讲解顺序逐步出现，用品牌蓝强调当前步骤。
- 动效以淡入、平移和局部放大为主，给观众留出阅读时间。
- 结尾展示产品名称、蓝卓 Logo 和明确的下一步信息。

## 首条视频建议结构

1. 介绍一个具体业务问题。
2. 用简洁图示展示产品处理流程。
3. 展示一个关键操作及结果。
4. 总结价值并展示品牌信息。

## 待确认

其他正式品牌色值、Logo 具体应用场景、目标观众、发布渠道、视频画幅、字幕语言和首条视频主题。


## 产品宣传视频参考

[用户提供的参考视频](supos-reference.mov)，约 85 秒，1920×1080，30 fps，含音轨。该素材用于产品宣传类视频参考。画面、节奏与声音的具体拆解待完整观看后补充。

## 待完善的制作规范

- 按产品宣传、功能演示和案例视频分别确定叙事结构与时长。
- 制定横竖屏构图、安全边距、字幕字号和位置。
- 明确片头、结尾、Logo、界面录屏与标注的模板及示例。
- 制定配音、背景音乐、音效和字幕的配合方式。
- 补充分镜模板、素材来源、事实核对和交付检查。

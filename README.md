# supOS-Free 传播设计规范

版本 1.0 草案。适用于 supOS-Free 的海报、视频封面与视频，先阅读品牌基础，再按制作场景查阅。品牌蓝为从 Logo 提取的 **#1448ED**。尺寸、边距和制作方法为起点，需通过项目样片及发布渠道验证。

## 场景入口

- [品牌基础](01-品牌基础.md) — 品牌色、Logo、字体与内容原则。
- [海报规范](02-海报规范.md) — 布局、画幅、层级与交付检查。
- [视频封面规范](03-视频封面规范.md) — 画幅、标题、主体和缩略图检查。
- [视频规范](04-视频规范.md) — 宣传、演示、案例的叙事、字幕、动效与交付。

## 素材与参考

仓库根目录提供七个蓝卓及 supOS Logo 原始 PNG。[产品宣传视频参考](supos-reference.mov)约 85 秒，1920×1080，30 fps，含音轨。当前环境未能解码其画面和声音，镜头、节奏及音乐风格待完整观看后提炼。

## 使用与维护

制作前确认受众、用途、渠道、尺寸、品牌标识和事实资料。完成后按对应场景的检查项校验，并用实际设备预览。正式品牌色卡、Logo 精确安全距离、字体授权、印刷色值与样片参数仍需确认。

规范结构参考 [Tier0 Design System](https://github.com/FREEZONEX/Tier0-Design-System)，品牌素材和颜色使用蓝卓提供的文件。
